# Frontend — My Portfolio

App **React + Vite** del progetto **Wallet Aggregator**.

👉 Per la documentazione completa (funzionalità, stack, avvio locale, variabili d'ambiente e deploy) vedi il **[README principale nella root del repository](../README.md)**.

## Comandi rapidi

```bash
npm install
npm run dev      # sviluppo (http://localhost:5173)
npm run build    # build di produzione (cartella dist/)
npm run preview  # anteprima della build
```
